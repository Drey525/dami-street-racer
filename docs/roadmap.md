# Dami Street Racer

## Product overview
A mobile-first street racing game with realistic handling, garage upgrades, offline play, and multiplayer competition.

## MVP goal
Build the foundation for a playable Android racing game with:
- one or more tracks
- a selectable car system
- progression and upgrades
- save data
- racing countdown and lap tracking
- garage and menu flow

## Phase plan
### Phase 1: functional prototype
- quick race
- garage with upgrades
- save system
- basic UI
- room for realism and tuning

### Phase 2: content and polish
- multiple tracks
- car variants
- local multiplayer
- nitro pickups and events
- better visuals and audio

### Phase 3: online multiplayer
- lobby system
- matchmaking
- leaderboards
- server-backed save and ranking

### Phase 4: production launch
- Play Store polish
- monetization
- analytics and crash reporting
- release testing and compliance

## Recommended engine
- Unity 3D
- C#

## Recommended backend
- Firebase or custom server for player profiles and leaderboards
- Photon for race networking
- Google Play Billing for monetization

## Main project structure
- `Assets/Scripts/Core`
- `Assets/Scripts/Data`
- `Assets/Scripts/Gameplay`
- `Assets/Scripts/UI`

## Important note
This game template is meant to be expanded into a production-ready title. The repo contains a practical starter foundation, not a finished market-ready game.
